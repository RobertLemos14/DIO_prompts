💬 ROTEIRO DE ENTREVISTAS

PERGUNTA 1: O que é uma API REST?
COMO RESPONDER: Explique que é um conjunto de rotas que seguem princípios de comunicação entre cliente e servidor usando HTTP.

PERGUNTA 2: Qual a diferença entre front-end e back-end?
COMO RESPONDER: Front-end é a interface que o usuário vê, back-end é a lógica e o banco de dados que sustentam a aplicação.

PERGUNTA 3: O que é o Git e por que é importante?
COMO RESPONDER: É um sistema de controle de versão que permite rastrear mudanças e colaborar em projetos.

PERGUNTA 4: Como funciona o ciclo de vida de um componente React?
COMO RESPONDER: Explique sobre montagem, atualização e desmontagem, e como hooks como useEffect ajudam a controlar isso.

PERGUNTA 5: O que é um CRUD?
COMO RESPONDER: É um conjunto de operações básicas em banco de dados: Create, Read, Update e Delete.
